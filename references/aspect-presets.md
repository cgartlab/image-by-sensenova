# 比例与尺寸预设

## 规则（API 实测）

`size` 可为 `auto` 或 `WIDTHxHEIGHT`，须满足：
- 宽、高均为 **32 的倍数**
- 宽、高均在 **512–4096**
- 宽高比 **≤ 3:1**

违反任一条返回 400。`size-check` 子命令可校验。

## 预设表（高画质默认）

| 比例 | 尺寸 | 像素量 | 约当 | 用途 |
|---|---|---|---|---|
| 1:1 | 3072×3072 | 9.4M | 正方形大图 | 头像、单图、社交媒体 |
| 16:9 | 4096×2304 | 9.4M | 4K 横屏 | 电影、桌面壁纸、横屏海报 |
| 9:16 | 2304×4096 | 9.4M | 4K 竖屏 | 手机壁纸、竖屏海报、Stories |
| 4:3 | 4096×3072 | 12.6M | 经典横画幅 | 打印、经典构图 |
| 3:4 | 3072×4096 | 12.6M | 经典竖画幅 | 海报、杂志 |
| 3:2 | 3840×2560 | 9.8M | 35mm 摄影 | 摄影打印 |
| 2:3 | 2560×3840 | 9.8M | 35mm 竖版 | 竖版摄影 |
| 21:9 | 4096×1760 | 7.2M | 超宽电影宽幅 | 电影片头、宽幅横幅 |

全部预设均为 32 倍数、512–4096、宽高比 ≤3，已实测通过。

## 选尺寸的决策

- **不知道选什么** → 1:1（3072×3072）
- **横屏/电影感** → 16:9（4096×2304）
- **竖屏/手机** → 9:16（2304×4096）
- **要 2.39:1 电影宽幅** → 用 21:9 生成，后期再加黑边到精确比例（API 不支持任意比例，靠预设 + 后期裁切）

## 自定义尺寸

满足规则即可，例：
- `2048×2048`（小正方形，省配额）
- `2016×1120`（≈16:9，省配额）
- `3072×1376`（超宽，接近 2.23:1）

```bash
python scripts/sensenova_gen.py gen -p "..." --size 2048x2048 --slug test
python scripts/sensenova_gen.py size-check --size 1920x1080  # → INVALID（1080 非 32 倍数）
```

## 降配额场景

免费额度 1500 次 / 5 小时。大量迭代时用小尺寸（如 1024×1024 或 2016×1120）快速试 prompt，定稿后再用预设大尺寸出最终图。

## 为什么不用 4096×4096

1:1 默认 3072×3072 而非 4096×4096：后者像素量翻倍（16.8M），生成更慢、output_tokens 更高，多数场景 3072 已足够。需要极限画质时手动 `--size 4096x4096`。
